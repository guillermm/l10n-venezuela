# ISLR Sale and Purchase Functionalities

[![License: AGPL-3](https://img.shields.io/badge/licence-AGPL--3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0-standalone.html)
[![OCA/l10n-venezuela](https://img.shields.io/badge/github-OCA%2Fl10n--venezuela-lightgrey.png?logo=github)](https://github.com/OCA/l10n-venezuela)

Copies the product ISLR concept to sale/purchase lines and then to the invoice so withholding can be applied at payment time.

## Configuration

No extra configuration. Requires `l10n_ve_withholding_islr`.

## Usage

Select the ISLR concept on quotation or purchase lines. It is copied to the invoice; the withholding itself is applied in Register Payment.
