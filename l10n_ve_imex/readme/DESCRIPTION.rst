Imex
====

Customs declarations DUA / DVI (Forma 86 / C-80 / C-81 / C-86) for
imports and exports:

- Link posted vendor bills to the declaration and confirm it.
- The invoice is marked as an import (SENIAT document type 05).
- The purchase book shows Form 86 and the expediente.
- The IVA TXT (99035) uses type 05, the form number as document and the
  expediente in the last column (import file 99086).
