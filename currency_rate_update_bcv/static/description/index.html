Currency Rate Provider BCV

Este módulo es un proveedor de tasa de cambio para Currency Rate Update.

Consultará la página web del Banco Central de Venezuela para obtener las tasas de:

Dólar (USD), Euro (EUR), Yuan (CNY), Rublo (RUB), Lira (TRY)

Migrado a 17.0 desde la rama 16.0 de OCA/l10n-venezuela (Luis Pinzón). El nombre técnico en 16.0 era res_currency_rate_provider_BCV; en 17.0 se llama currency_rate_update_bcv, igual que en 18.0. En esta rama también se hizo backport a 17.0 del endurecimiento del scrap publicado en currency_rate_update_bcv 18.0 (timeout (10, 60), chequeo HTTP 200 y claves de fecha ISO). Depende de currency_rate_update (OCA/currency 17.0).

Configuration

  1. Instalar currency_rate_update de OCA/currency (rama 17.0).
  2. Instalar este módulo.
  3. Contabilidad > Configuración > Currency Rates Providers: crear un proveedor BCV scrapping y marcar USD (y EUR/CNY/TRY/RUB si aplica).
  4. Activar Automatic Currency Rates (OCA) en Ajustes, o actualizar a mano.

La compañía debe usar VES como moneda: el BCV publica bolívares por divisa.

Usage

Accounting > Configuration > Currency Rates Providers > Update Rates. El BCV solo publica la tasa del día (no hay histórico en este proveedor).
