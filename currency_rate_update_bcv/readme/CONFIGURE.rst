1. Instalar ``currency_rate_update`` de OCA/currency (rama 17.0).
2. Instalar este módulo.
3. Contabilidad > Configuración > Currency Rates Providers: crear un
   proveedor *BCV scrapping* y marcar USD (y EUR/CNY/TRY/RUB si aplica).
4. Activar *Automatic Currency Rates (OCA)* en Ajustes, o actualizar a mano.

La compañía debe usar VES como moneda: el BCV publica bolívares por divisa.
