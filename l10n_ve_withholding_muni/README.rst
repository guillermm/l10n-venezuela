Municipal Withholding Venezuelan Laws
=====================================

Vendor municipal withholding (retención municipal) for Odoo 17.

Uses the official municipalities from ``territorial_pd``. Configure the
economic activity (rate per ordinance) on that municipality, or set the
rate manually on the supplier. Applied when registering a payment
(write-off). This is not IMI / patente municipal self-assessment.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Set the municipal withholding journal and account on the company.
Create economic activities (rate) on the official municipality from
``territorial_pd``, then assign the activity on the supplier. The
address municipality and the withholding municipality are the same
record.

Usage
=====

1. Post the vendor bill.
2. Register Payment and review the municipal withholding amount.
3. Confirm; the voucher is created with the payment (no orphan entry).
4. Accounting > Vendors > Municipal Withholdings.
