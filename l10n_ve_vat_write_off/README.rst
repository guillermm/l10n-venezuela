VAT Write Off (Ajustes de Crédito Fiscal)
=========================================

Manual adjustment of non-deductible VAT credits. Creates a journal entry
and adds a type-04 line to the draft purchase (or sale) fiscal book of
the same period, reducing the VAT credit.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Choose debit and credit accounts on each write-off (they must differ).

Usage
=====

Accounting > Reporting > VAT Write Offs: create the voucher, set accounts
and amount, then post.
