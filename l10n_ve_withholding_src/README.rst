Compromiso de Responsabilidad Social (SRC)
===========================================

SRC withholdings for public-sector contracts (Ley de Contrataciones Públicas)
on Odoo 17. Mark the supplier as subject; the default rate is 5 % (company
setting). Applied when registering a payment (write-off).

**Table of contents**

.. contents::
   :local:

Configuration
=============

Set the SRC journal and account on the company, and the applicable rate on
eligible suppliers.

Usage
=====

1. Post the qualifying vendor bill.
2. Register Payment and review the SRC amount.
3. Confirm; the voucher is created with the payment.
4. Accounting > Vendors > SRC Withholdings.
